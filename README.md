## Stroke Prediction Model

## Overview
This project explores machine learning techniques for predicting stroke outcomes using health-related data. It uses Python, Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn.

## Dataset
The dataset contains information such as age, hypertension, heart disease, average glucose level, BMI, smoking status, and stroke outcome.

Dataset file: `healthcare-dataset-stroke-data.csv`

## Models Used
- Logistic Regression
- Random Forest Classifier

## Project Workflow
1. Dataset inspection and EDA
2. Data cleaning and handling missing values
3. Categorical encoding and correlation analysis
4. Train-test split
5. Model training and evaluation
6. Performance comparison

## Requirements
- Python 3
- Jupyter Notebook / VS Code
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## How to Run
1. Download or clone this repository.
2. Install the required libraries.
3. Open `spm.ipynb` in Jupyter Notebook or VS Code.
4. Run the notebook cells in order.

Install the libraries with:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

## Disclaimer
This project is for educational purposes only. The models are not clinically validated and should not be used for medical diagnosis or treatment decisions.
